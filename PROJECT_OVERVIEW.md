# AeroPulse-Air — Hourly PM2.5 Forecasting

Forecasts a synthetic PM2.5-like concentration from calendar cycles, wind, rainfall, temperature, episodic emissions, and recent observations. No monitoring-station data are used.

Synthetic hourly data; chronological rolling one-step evaluation. This simulator is not calibrated to a location or monitoring network and is not an air-quality warning system. Real public station data must be evaluated with station/time-separated splits and applicable dataset terms.
