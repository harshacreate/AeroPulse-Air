# AeroPulse-Air — Hourly PM2.5 Forecasting

**Sector:** Environment  
**Task:** Hourly air-quality regression

Forecasts a synthetic PM2.5-like concentration from calendar cycles, wind, rainfall, temperature, episodic emissions, and recent observations. No monitoring-station data are used.

## Data and split

The offline demo is generated by `aeropulse/data.py`; it does not download or redistribute external data. Its deterministic simulator creates an hourly series with domain-specific seasonal, weather, trend, event, and lag features. The data are illustrative and do not represent real operators, customers, or environmental conditions.

The holdout is chronological (first 75% for training, final 25% for evaluation). The test is a **rolling one-step** evaluation: each row may use the actual preceding observations to construct its lag features. It does not measure a recursively generated multi-hour forecast.

## Models and evaluation

- **Baseline:** 24-hour seasonal naive forecast (`lag_24`).
- **Stronger model:** histogram gradient-boosting regression trained on the training period only.
- **Metrics:** MAE, RMSE, R², sMAPE, 90th-percentile absolute error, and mean bias. No benchmark is claimed in advance; the CLI prints the measured synthetic holdout results.

## Limitations

This simulator is not calibrated to a location or monitoring network and is not an air-quality warning system. Real public station data must be evaluated with station/time-separated splits and applicable dataset terms.

## Run

    python3 -m venv .venv
    . .venv/bin/activate
    python -m pip install -e ".[test]"
    python -m aeropulse.train --seed 42 --samples 1200
    python -m pytest -q

`make setup`, `make train`, and `make test` are shortcuts. Python 3.9 or newer is required.

## Files

- `aeropulse/data.py`: deterministic domain simulator and lagged feature construction.
- `aeropulse/split.py`: forward-only holdout.
- `aeropulse/model.py`: seasonal-naive comparison, stronger regressor, metrics.
- `aeropulse/train.py`: training/evaluation CLI.
- `tests/`: generator, split, metric, and CLI tests.
- `.github/workflows/ci.yml`: test and CLI smoke job.
